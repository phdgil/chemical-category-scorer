Draft figure and table legends for Journal of Cheminformatics

Figure 1. Final rebuild workflow
Workflow used in the final manuscript run. Broad chemical product categories were extracted from the PubChem Classification Browser HID 72 chemical-classes branch, converted from CIDs to canonical SMILES, deduplicated at the structure level, and rebuilt with retained-cross-category negatives. Each scorer combined descriptor-range support with structural-pattern evidence and was benchmarked against raw RDKit QED on the same evaluation set before local-first software deployment.

Figure 2. Final scorer performance versus QED
Area under the ROC curve for each final chemical product-category scorer and for raw RDKit QED on the same rebuilt evaluation sets. All eleven final scorers exceeded QED, with the largest margins observed for surfactants, endocrine disruptors, solvents, fragrances, and flavoring agents.

Figure 3. Descriptor-pattern composition of final scorers
Summary of descriptor-range count, structural-pattern count, and descriptor-pattern mixing weight for the eleven final category scorers, including the cross-regime-selected Han endocrine model. The figure illustrates that the rebuilt models remained mixed interpretable scorers rather than collapsing into purely descriptor-based rules.

Figure 4. Local-first software deployment modes
Two local-first delivery modes built on the same final scoring engine. The desktop application supports single-SMILES scoring, batch CSV processing, molecule visualization, and matched-pattern review, while the Python library exposes QED-like import functions for RDKit-based workflows. Both modes execute locally so that confidential molecular structures do not need to be submitted to a hosted service.

Table 1. Final category benchmark summary
Final full-positive benchmark results for the eleven selected categories after CID-to-SMILES conversion, deduplication, retained-cross-category negative construction, and Tanimoto filtering. Same-regime raw RDKit QED values are shown for direct comparison.

Table 2. Final scorer composition summary
Descriptor and structural-pattern content of the final broad-category scorers, including selected descriptor set, selected pattern set, descriptor-pattern mixing weight, and selected optimization route.
