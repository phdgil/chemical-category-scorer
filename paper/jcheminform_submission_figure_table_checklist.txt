Introduction drafting plan
- Para 1: establish interpretable molecular scoring and QED as the conceptual anchor.
- Para 2: define why broad chemical product-category scoring matters in practice.
- Para 3: review related scorer/alert literature (QED, natural-product likeness, synthetic accessibility, Bioalerts).
- Para 4: identify the unresolved gap: no common broad-category framework and no explicit treatment of positive capping or overlapping-category negatives.
- Para 5: state the PubChem HID72 setting, the methodological risks found in exploratory work, and the present study objective.


Main table submission rule
- For Journal of Cheminformatics, normal main-text tables should stay in the manuscript file (Word/Docx/RTF/LaTeX) at the relevant position or, if long, at the end of the manuscript with in-text callouts.
- Only very large tables or tabular datasets that exceed one page or A4/Letter width should be submitted as additional files (for example CSV or XLS).
- Therefore Table 1 and Table 2 should be embedded in the main manuscript, while extended benchmark tables can remain supplementary CSV files.
