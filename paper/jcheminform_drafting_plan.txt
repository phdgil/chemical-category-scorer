Main table submission rule
- For Journal of Cheminformatics, normal main-text tables should stay in the manuscript file (Word/Docx/RTF/LaTeX) at the relevant position or, if long, at the end of the manuscript with in-text callouts.
- Only very large tables or tabular datasets that exceed one page or A4/Letter width should be submitted as additional files (for example CSV or XLS).
- Therefore Table 1 and Table 2 should be embedded in the main manuscript, while extended benchmark tables can remain supplementary CSV files.
