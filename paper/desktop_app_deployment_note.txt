Desktop deployment note for manuscript preparation

The current study already has a working desktop app under `app/desktop_app.py` with a Windows launcher `app/run_desktop_app.bat`.

Reason to keep the app as desktop-first instead of web-first:
- many industrial users treat molecular structure as confidential intellectual property
- a local desktop workflow reduces concern that structures could be exposed through remote inference calls or accidental server logging
- GitHub distribution is compatible with this goal because the repository distributes code and models, not user structures

Recommended manuscript phrasing:
"To support industrial use cases where molecular structures are commercially sensitive, the final scorers were packaged as a local-first desktop application rather than a web-only service. The application performs descriptor calculation and scoring on the user workstation and writes outputs locally, reducing routine structure-exposure risk during evaluation workflows."
App sync update (2026-07-14): the desktop app now loads the final rebuilt broad-category scorers directly from app/data/models and no longer points to the earlier legacy Kim/Lee/Choi/PubChem model mix.
The same scoring assets are also packaged as an importable Python library so users can call category scorers programmatically in a manner analogous to an RDKit QED-style function while keeping the computation local.
